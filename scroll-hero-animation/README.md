# Scroll-Driven Hero Section Animation

A responsive frontend assignment built with HTML, CSS and vanilla JavaScript.

## Features
- Full-screen sticky hero section
- Letter-spaced "WELCOME ITZFIZZ" headline
- Staggered initial-load animations
- Three animated impact metrics
- Scroll-progress-driven main visual
- Smooth interpolation with requestAnimationFrame
- Transform-based translate, scale and rotate animation
- Responsive mobile layout
- Reduced-motion accessibility support

## Run
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Files
- `index.html` - page structure
- `style.css` - layout, car illustration and animations
- `script.js` - scroll progress and interpolation logic
- `assets/` - available for replacement images/assets

The car is drawn with CSS, so the project works immediately without downloading an external image.
